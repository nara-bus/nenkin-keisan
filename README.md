# 年金手取り計算（広陵町）

夫婦の年金収入を入力すると、所得税・住民税・国民健康保険税・介護保険料を差し引いた
世帯の手取り額を自動計算するPWAアプリ。

## 使い方

GitHub Pagesを有効にすると `index.html` がそのまま動く。インストール不要、
ブラウザで開くだけ。オフラインでも動作する（Service Workerでキャッシュ）。

## 計算の前提

- 広陵町・令和8年度の税制、国民健康保険税率、介護保険料（第9期）を使用
- 夫婦とも75歳未満・国民健康保険に加入、年金収入のみ、扶養親族なし
- 妻の所得が配偶者控除の範囲内であれば、夫の同一生計配偶者として自動判定
- 社会保険料控除は世帯の国保税・介護保険料の合計額を夫がまとめて負担するものとして計算

65歳未満（40〜64歳）の年齢入力にも一部対応しているが、国保の介護納付金分の按分は
未実装。実際の税額は前年の他の所得や控除内容によって変動するため、正式な金額は
役場・年金事務所の試算を確認すること。

## ファイル構成

```
index.html      アプリ本体（計算ロジック含む単一ファイル）
manifest.json   PWAマニフェスト
sw.js           Service Worker（オフラインキャッシュ）
icon-192.png    アプリアイコン
icon-512.png    アプリアイコン（大）
```

## バージョン管理

`sw.js` の `CACHE_NAME` / `APP_VERSION` は `YYYYMMDD-NNN` 形式。更新時は
両方を必ず同期させること。
